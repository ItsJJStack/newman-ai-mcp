# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues or discussions.

Once GitHub's private vulnerability reporting is enabled for this repository, use **Report a vulnerability** on the repository's **Security** tab. This creates a private advisory visible only to the maintainers and the reporter.

If private vulnerability reporting is not available, do not post exploit details publicly. Open a minimal issue asking the maintainers to enable a private reporting channel, without including sensitive details.

Include the affected version, impact, and minimal reproduction steps. Redact API keys, tokens, passwords, private collection data, and URLs containing credentials or query parameters.

The maintainers will acknowledge reports as soon as practical and coordinate a fix and disclosure with the reporter.
